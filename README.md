# BTCTimeSeries
This project was completed for the A level computer science NEA. The data has been sourced using python libraries as they have greater support for financial data, while the code for the machine learning has been written in C++/CUDA to enable parallelisation while also implementing algorithms like matrix multiplication from scratch to tick of section A skills. The focus of this model is to output a "Buy" or "Sell" signal based on historical market data, collected and stored in a database within dataprocessing. The model is designed to be trained using fp32s on an NVIDIA GPU. Parameters stored in this project are the result of training on an NVIDIA 2080 Super graphics card on about 10 years of data ending around the end of 2025. The data must first be normalised using z score normalisation before being input into the network and after all metrics have been calculated. The CLS token contains trainable parameters and must be appended to the end of the sequence to allow for classification as this vector will be the output of the transformer informed by historical data. 31 days of data has been chosen since months are easy to work with, and given that the CLS token is appended 32 tokens will be passed in with a given batch, and given that 32 channels are used this fits nicely on 1 warp within the GPU. Financial systems are assumed to be markovian so more data is not needed, the feature dimension is more important so 32 different financial metrics have been used. The full details of this are laid out in more depth in the analysis section.
